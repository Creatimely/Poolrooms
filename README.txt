POOLROOMS - jeu d'exploration liminale (Three.js, 100% hors-ligne)
1) Dézippe le dossier  2) Ouvre index.html dans Chrome / Edge / Firefox / Safari  3) Clique sur "Entrer".
Si la souris ne se capture pas en ouvrant le fichier directement, lance un mini-serveur :
   python -m http.server 8000   puis ouvre http://localhost:8000
Objectif : trouver 10 clés (piliers, tunnels, salles secrètes), les insérer dans la grande porte de la salle de départ.
Commandes : ZQSD/WASD, souris, Maj courir, Espace sauter/glisser, C plonger, E interagir, M ou clic sur la minimap = carte, Échap pause.
Téléphone : "Tactile" dans Réglages (bouton Agir pour interagir, tape la minimap pour la carte).
Chaque monde a un numéro : tu peux le charger dans "Monde". Qualité Basse/Moyenne si ça rame. La musique (main_theme.mp3) joue sur le menu et à la victoire.
